\section*{Impact Statement}
Pruning spatial tokens can lower the memory needed to answer questions about a 3D scene. It can also remove details needed to describe or locate an object: the same pruning budget that performed well on ScanQA reduced captioning and multi-object referring scores. Applications that rely on these details should validate the pruning budget on their own tasks. We measured application time on one GPU, but did not measure energy use; the reported reduction in model FLOPs therefore cannot quantify an environmental benefit.
