\begin{abstract}
3D large multimodal models process hundreds of spatial tokens to answer questions about a scene, describe objects, or locate them from language. Attention can rank tokens for removal, but the ranking changes with depth, leaving open when to prune. We propose GeoGate, a training-free schedule that runs the full sequence through block L14, reuses FastV's last-prompt attention to select spatial tokens, and compacts every layer's prompt cache while preserving text tokens and original rotary positions. On ScanQA validation, where we selected the schedule, LLaVA-3D retaining 128 spatial tokens scores 1.22 and 1.03 exact-match points above selected L2 and L8 controls at matched analytical language-model cost. At 10\% retention, LLaVA-3D uses 42.1\% fewer analytical language-model FLOPs and 78.5\% less initial prompt-cache storage, but application time falls by only 0.8--1.4\% on one H100; on SQA3D validation, the same schedule costs 3D-LLaVA 0.95 exact-match points relative to its unpruned baseline. Code is available at \url{https://anonymous.4open.science/r/GeoGate-E8AC/}.
\end{abstract}
